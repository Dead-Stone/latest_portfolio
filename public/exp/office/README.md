# Office gallery photos

Drop workplace photos here to show them in the **Gallery** section on the portfolio page.
If this folder has no images, the gallery section is hidden automatically.

## Filenames

Use these exact base names (`.jpg`, `.jpeg`, `.png`, or `.webp`):

| File name        | Experience        |
|------------------|-------------------|
| `nextphase-ai`   | NextPhase AI LLC  |
| `gembizz`        | Gembizz LLC       |
| `sjsu`           | San José State University |
| `astranetix`     | Astranetix Corporation |
| `flatirons-ai`   | Flatirons AI LLC  |
| `deloitte`       | Deloitte          |
| `turito`         | Turito / YuppTV   |
| `cdac`           | CDAC              |

## Examples

- `nextphase-ai.jpg`
- `deloitte.png`
- `sjsu.webp`

You do not need every file — only roles with a matching image appear on the wall.
